# NFR-TC-06 — الاعتمادية وتعذر الخدمات وإعادة المحاولة

- المتطلب/النوع: `USR-NFR06` — اعتمادية وتكامل حرج.
- السيناريو: تعذر اتصال قبل الحفظ، وفقد الرد بعد الاعتماد، وتعذر وصفة/بحث.
- الشروط: Emulator وحساب وطلب تجريبي؛ operationId ثابت؛ وسيلة لتعطيل الشبكة أو إسقاط الرد؛ حفظ الحالة قبل الاختبار.
- الخطوات: افصل الاتصال قبل الحفظ وتحقق من عدم ظهور نجاح؛ أعد مع قطع الرد بعد الإرسال والاعتماد؛ اتصل وأعد الأمر بالمعرّف نفسه؛ افحص عدد الآثار؛ جرّب تعذر تحليل الوصفة وبحثًا بلا نتائج.
- القبول: لا نجاح زائف؛ تبقى آخر حالة مؤكدة؛ لا يتكرر الأثر عند إعادة المعرف؛ تسمح حالة عدم النتائج بتعديل البحث.
- اختبار آلي مساعد: `flutter test test/order_notifications_regression_test.dart` يغطي محاكاة إعادة استخدام العملية/النقر المزدوج، وليس انقطاع شبكة جهاز حقيقي.
- الدليل: الحالات قبل/بعد وعدد الآثار الدائمة ورسائل الخطأ.
