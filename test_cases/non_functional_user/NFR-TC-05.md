# NFR-TC-05 — خصوصية البيانات وعزل الملكية

- المتطلب/النوع: `USR-NFR05` — خصوصية وتكامل.
- السيناريو: محاولة حساب قراءة/تعديل بيانات حساب آخر وفحص ما يصل للصيدلية والإدارة.
- الشروط: حسابان ومستفيدان ووصفة وملف وطلب؛ هويات اختبار للصيدلية والإدارة؛ Emulator وsnapshots قبلية.
- الخطوات: جرّب من A الوصول إلى معرّفات B مباشرة عبر Firestore وStorage والخدمات؛ افحص حقول استجابات الصيدلية والإدارة؛ قارن البيانات قبل وبعد.
- القبول: لا يقرأ أو يعدل A بيانات B؛ لا ترسل بيانات صحية/دوائية خاصة للصيدلية أو الإدارة؛ تقتصر بيانات الصيدلية على ما يلزم للطلب المرتبط؛ لا تغييرات غير مصرح بها.
- أمر التنفيذ: `npm run test:emulator` من `functions` لاختبارات العزل. يلزم أيضًا فحص استجابات الجهات لاختبار حدود المشاركة.
- الدليل: نتائج القراءة/الكتابة وقائمة الحقول بعد حجب المعرفات الشخصية.
