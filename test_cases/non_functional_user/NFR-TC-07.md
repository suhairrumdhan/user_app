# NFR-TC-07 — التذكيرات المحلية دون اتصال

- المتطلب/النوع: `USR-NFR07` — عمل محلي واعتمادية.
- السيناريو: إنشاء تذكيري دواء وموعد واستلامهما دون شبكة ثم إدارة الجدولة.
- الشروط: جهاز Android؛ حسابان ومستفيدان؛ أذونات إشعار؛ موعدان مستقبليان قريبان ومنطقة زمنية مسجلة.
- الخطوات: أنشئ التذكيرين لكل مالك؛ افصل الإنترنت وانتظر؛ عدّل موعدًا وأوقف تذكيرًا ثم أعد تفعيله واحذف الآخر؛ بدّل الحساب وافحص القائمة والإشعارات.
- القبول: تظهر التذكيرات الفعالة بموعدها وفق إذن الجهاز؛ تلغى الجدولة القديمة بالتعديل/الإيقاف/الحذف؛ لا تختلط الحسابات.
- التنفيذ: يدوي على Android؛ اختبارات الوحدة المكتبية لا تثبت إشعار نظام التشغيل.
- الدليل: الجهاز والأذونات والأوقات ولقطات إشعار منقحة.
